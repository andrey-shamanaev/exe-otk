# Как пользоваться (сотрудники и админ)

## Размещение на сетевой папке

Папка, например:

```
\\сервер\...\Тест СП 53-101-98\
  Тест_СП_53.exe
  questions.json
  results.json
  lock.json
  1.png … 37.png
```

Всем сотрудникам раздайте **ярлык** на `Тест_СП_53.exe` (или откройте папку и запускайте exe).

Python и браузер **не нужны**. Чёрного окна сервера нет.

## Прохождение теста

1. Запустите программу.
2. Введите ФИО, выберите часть (1 или 2), нажмите «Начать тестирование».
3. Если кто-то уже проходит тест — появится сообщение «Сайт занят» с ФИО и оставшимся временем. Дождитесь окончания или истечения блокировки (~45 мин).
4. Ответьте на вопросы, в конце — «Завершить».
5. Увидите процент и разбор ошибок.

## Администратор

- На главном экране: «Отчёт для администратора».
- Пароль по умолчанию: **admin**.
- Можно посмотреть сводку, карточки сотрудников, время по вопросам.
- **Скачать результаты** — подробный CSV (разделитель `;`, UTF-8).
- **Очистить всё** — удаляет все попытки из `results.json` (необратимо).

## Если «занято» слишком долго

Закройте программу у того, кто «завис», либо вручную откройте `lock.json` и замените содержимое на:

```json
{"until": 0}
```

## Требования

Windows 10/11. Интернет не нужен.
